# DocuFlow User Guide

## 1. Overview
DocuFlow is an intelligent document processing and workflow automation platform that extracts, validates, normalizes, reviews, and generates reports from business documents.

## 2. Roles & Permissions
- **Administrator:** Full system access, user management, configuration, logs, reports.
- **Processing Manager:** Upload documents, trigger processing, review and edit extractions, approve records, generate reports.
- **Viewer:** Read-only access to documents, validated results, and reports.

## 3. Core Workflows
1. **Login:** Access the system at `/login` using assigned credentials.
2. **Upload Documents:** Navigate to **Documents > Upload Document**. Drag and drop or browse files (.pdf, .csv, .xlsx, .png, .jpg).
3. **Start Processing:** Choose default or custom field extraction rules and queue the job.
4. **Review & Corrections:** Open **Processing > Review & Approvals**. Correct highlighted errors or missing values.
5. **Approve & Export:** Mark records approved and export structured Excel or PDF reports.
